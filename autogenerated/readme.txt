Notes on Auto-Generated Files and Build Process
-----------------------------------------------

1- Generation Context
Auto-generated files are produced with CONFIG_TFM_SPM_BACKEND_IPC enabled.

2- Manual Enhancements for IPC and SFN Models
After generation, these files are manually updated to support both IPC and SFN models.
For partitions that specify the model as SFN in the YAML configuration, the generated code consistently defines:
C#define TFM_SP_<partition>_MODEL_IPC  0#define TFM_SP_<partition>_MODEL_SFN  1Show more lines
These definitions remain unchanged even when CONFIG_TFM_SPM_BACKEND_IPC is enabled. They should be regarded as static indicators derived from the YAML configuration, not as a reflection of the actual runtime implementation.

3- Integration into SDK Build
Once auto-generation is complete, the files located under autogenerated/secure_fw/partitions are copied back into the source tree to be included in the TF-M build within the SDK.
